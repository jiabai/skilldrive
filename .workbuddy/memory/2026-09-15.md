## 桌面端 local skills 页面增加搜索框

需求：在桌面端（不是 web 前端）的 local skills 页加搜索框。

关键定位结论：
- 「local skills 页面」在 `desktop-client/src/components/local-skills-view.tsx`，由 `App.tsx` 在 `view === "local-skills"` 时渲染。web 前端的 `frontend/src/app/skills/page.tsx` 本来就已有搜索框，不要混淆。
- 该组件是纯受控组件，数据来自 props 里的 `snapshot`（Electron IPC `desktopClient.refreshLocalSkills()`），没有 SWR/react-query，手动 refresh + useState。

实现（纯前端过滤，未动后端与 IPC）：
- `local-skills-view.tsx`：新增 `searchTerm` state；在现有 `groupedRows` useMemo 之后加一层 `visibleGroups`；模块级新增 `matchesSearchTerm()`，匹配 name / description / packageRootPath / sourceDisplayNames，大小写不敏感。
- 渲染改用 `visibleGroups`；`selectedGroup` 仍从 `groupedRows` 找，这样搜索时右侧详情面板不会被动关闭（有意取舍）。
- 空态区分两种：`groupedRows.length === 0` 用 `copy.empty`，`visibleGroups.length === 0` 用新增的 `copy.noMatch(term)`。
- 复用 `@/components/ui-primitives` 的 `Input`（type="search"）+ `Button`（ghost，清除按钮），未新建组件。
- i18n 三个文件都要改：`types.ts`（localSkillsView 段）、`en-US.ts`、`zh-CN.ts`。新增 key：searchLabel、searchPlaceholder、clearSearch、noMatch、filteredCount。
- `styles.css` 新增 `.local-skills-toolbar`（flex + gap），注意按钮 class 是 `.btn` 不是 `.button`。

## 启动 desktop-client 看界面的坑（实测可用配方）

在本机从命令行启动 Electron 应用，要绕过三个坑，缺一个都起不来：

1. **环境里预先设了 `ELECTRON_RUN_AS_NODE=1`**（本机 shell 自带），会让 electron 以纯 Node 模式运行主进程，报
   `TypeError: Cannot read properties of undefined (reading 'exports') at cjsPreparseModuleExports`。
   必须清掉。
2. **沙箱里 GPU 进程起不来**，报 `GPU process isn't usable. Goodbye.`，必须加 `--no-sandbox --disable-gpu`。
3. **进程必须常驻在命令前台**：用 `&` 后台启动的话，命令一返回进程就被回收；PowerShell 的 `Start-Process` 也一样会被回收（`Get-Process` 查到 NOTRUNNING）。

可用命令（Bash 工具，`run_in_background=true`，让任务一直挂着）：

```
cd /d/Github/skilldrive/desktop-client && env -u ELECTRON_RUN_AS_NODE ./node_modules/electron/dist/electron.exe . --no-sandbox --disable-gpu
```

验证存活用 `ps -W | grep -i electron`（`tasklist` 在本机查不到，别用）。正常会有 4 个进程。

注意：Bash 里 `cmd /c start` 被安全策略直接拦截（"Invoking cmd.exe from Bash bypasses all command validation"），不能用它脱离启动。PowerShell 工具的 stdout 会被吞，要回显就写文件再读。
