## 启动 desktop-client 做人工核验（环境坑，重要）

bicho 要求启动看 Agent 视角效果。踩到两个环境坑，已解决，记下来避免重复排查：

1. **`ELECTRON_RUN_AS_NODE=1` 会污染子进程**。WorkBuddy 自身是 Electron 应用，会向子进程注入该变量，导致 `electron.exe` 以纯 Node 模式运行，主进程第一行 `import { app } from "electron"` 就炸：`TypeError: Cannot read properties of undefined (reading 'exports')`（栈里有 `cjsPreparseModuleExports`）。日志末尾写 `Node.js v20.18.3` 而不是 Electron 版本，就是这个信号。启动时必须 `env -u ELECTRON_RUN_AS_NODE`。
2. **GPU 进程在沙箱里起不来**，报 `FATAL:gpu_data_manager_impl_private.cc(423) GPU process isn't usable. Goodbye.`。加 `--no-sandbox --disable-gpu --in-process-gpu --disable-gpu-sandbox --disable-features=VizDisplayCompositor` 后正常。

可用启动式（dev 模式，改 renderer 免重新打包）：

```
npx vite --port 5199 --strictPort        # 后台
env -u ELECTRON_RUN_AS_NODE VITE_DEV_SERVER_URL=http://localhost:5199 \
  ./node_modules/electron/dist/electron.exe . --no-sandbox --disable-gpu --in-process-gpu --disable-gpu-sandbox --disable-features=VizDisplayCompositor
```

改了 `electron/` 下的主进程代码才需要 `npx vite build --config vite.electron.config.ts`（preload 同理换 `vite.preload.config.ts`）。

截屏验证走不通：PowerShell 工具禁止 `Add-Type`（无法用 .NET 截屏），Bash 里调 powershell.exe 被安全策略拦。改用 vitest 渲染测试验证 UI 更可靠，已新增 `src/__tests__/agent-skills-view.test.tsx`（8 个用例：只列已安装、按有效数排序、共享目录标注、下钻只看该 agent、返回与查看回调、missing / empty 两态）。
