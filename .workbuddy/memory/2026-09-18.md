## 改动：审核摘要表格「目标」列隐藏已安装 agent

需求：`updates` 页（All pending updates）里「审核摘要」卡片表格的 Targets 列，不再列出 `installed`（已安装）状态的 agent，只留 `not-installed` / `update`。

改动文件（trivial 路径，未走 spec + plan）：

- `desktop-client/src/components/updates-review-workspace.tsx`
  - 新增 `getWriteTargetResults()`，过滤掉 `contentComparison === "installed"`。
  - `getTargetSummary()` 改为接收「全部检查结果 + 可写入结果」两个数组：无检查结果时仍显示 "Refresh check..."；有结果但全是 installed 时返回 `null`（此时计数已显示 0）。
  - 行内计数由 `snapshot.targetAgentIds.length`（全部已配置目标）改为可写入目标数；检查结果缺失时仍回退到原口径，避免行为变化。
- `desktop-client/src/__tests__/app.test.tsx`
  - 新增用例 "shows only actionable agent targets in the review table Targets column"，覆盖「隐藏 Installed + 计数为 1」。断言用 `within(getByRole("table"))` 作用域，因为 action bar 与摘要侧栏也会渲染同样的 "1 write target" 文案，`getByText` 会命中 3 处。

保留行为：`error` 状态的 agent 仍然显示（那是需要处理的问题，不是噪音）。

验证：`vitest run src/__tests__/app.test.tsx` 53 passed；全量 `vitest run` 241 passed / 2 failed，2 个失败都是 symlink 用例（`skill-package-tree.test.ts`、`project-skill-import-service.test.ts`），属本机 Windows 无法建符号链接的环境问题，与本次改动无关。
